Build

  • Developed scalable backend services for the enterprise web application behind vehicle ordering, packaging and supply chain operations handling high-volume transactions.
  • Built serverless APIs on AWS Lambda with Express and Apollo GraphQL, behind API Gateway with a Lambda authorizer that checks every request.
  • Designed the service layer with TypeORM and the pg driver on Amazon RDS for PostgreSQL, integrating S3 and other teams' APIs, improving reliability and processing efficiency.
  • Enhanced backend services and GraphQL APIs as part of enterprise modernization, enabling faster data access across applications.

Automate

  • Built EventBridge-scheduled batch processes for vehicle and part line planning, daily order release, order summaries and business calculations, cutting manual intervention by 75%. Users now only make manual adjustments for daily needs.
  • Ran lighter batches on AWS Lambda and heavier ones on ECS, and chained dependent batches with Step Functions.
  • Sped up data loads by bulk-importing CSV files from S3 into PostgreSQL instead of row-by-row inserts.
  • Delivered results as files for downstream systems and data in our database, and notified users by email through SNS and SES.
  • Earned multiple client appreciations for this automation, which replaced costly externally hosted processing and saved the client significant costs.

Quality & delivery

  • Implemented automated functional and regression testing with Mocha and Chai, raising test coverage to 85% and reducing production defects.
  • Shipped changes through CI/CD pipelines to QA, then versioned GitHub releases and template-based deployments for web services and ECS batches, with a disaster recovery (DR) region.
  • Supported production with CloudWatch Logs, alongside design discussions, code reviews and performance tuning.

Collaborate & grow

  • Worked with business analysts, QA and developers in Agile teams to deliver timely, production-ready releases.
  • Used AI-assisted tools (GitHub Copilot, Claude) to speed up development cycles and reduce repetitive implementation effort.
  • Promoted from L0 to L1 and recognized with a commendable performance rating for ownership and business-critical delivery.
